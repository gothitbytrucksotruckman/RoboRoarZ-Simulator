API Referensi Script
sensors.cargo

.count (0-3), .totalMassKg, .hasContact, .cubes array.

sensors.checkpoints / sensors.navTarget

Checkpoint AprilTag di bawah kubus. .navTarget = koordinat target berikutnya setelah tag terpindai (null sebelum pindai pertama).

Jarak minimum rintangan depan [-deg, +deg].

robot.setVelocity(vx, vy, omega)

vx = maju/mundur, vy = strafe lateral, omega = rotasi.

robot.getLoadedMass()

Mengembalikan bobot total robot + kargo aktif dalam kg.

robot.log(pesan)

Mencetak pesan langsung ke Simulator Console.
